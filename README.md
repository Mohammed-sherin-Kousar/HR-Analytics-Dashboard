# HR Analytics Dashboard

##  Project Overview

Developed an interactive **HR Analytics Dashboard using Power BI** to analyze employee attrition, workforce demographics, salary, job roles, overtime, satisfaction, and other HR-related metrics. The dashboard transforms employee data into interactive KPIs and visual insights to support workforce analysis and reporting.

##  Objective

* Analyze employee attrition and workforce patterns.
* Track key HR performance indicators.
* Analyze employee demographics, salary, job roles, and departments.
* Identify patterns related to overtime, satisfaction, and employee experience.
* Build an interactive dashboard for HR reporting and analysis.

##  Technologies Used

* Power BI
* DAX
* Power Query
* Excel / CSV
* Data Visualization

##  Key Steps

* Imported and explored the HR employee dataset.
* Performed data preparation and transformation using Power Query.
* Created calculated measures using **DAX**.
* Developed HR KPIs and interactive visualizations.
* Analyzed attrition across departments, job roles, demographics, and other employee attributes.
* Added interactive filters and slicers for dynamic analysis.
* Designed an interactive Power BI dashboard for HR reporting.

##  Dashboard Analysis

* Employee Count
* Attrition Rate
* Department-wise Attrition
* Job Role Analysis
* Salary / Monthly Income Analysis
* Overtime Analysis
* Job Satisfaction
* Employee Demographics
* Years at Company
* Years in Current Role
* Years Since Last Promotion

##  Result

* Developed an interactive Power BI dashboard for analyzing workforce and attrition trends.
* Created KPI-driven reports for quick HR performance monitoring.
* Enabled dynamic analysis using filters and slicers.
* Visualized employee characteristics and attrition patterns across multiple HR dimensions.
* Converted raw employee data into an interactive business intelligence report.
